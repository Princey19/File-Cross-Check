# File Cross-check app
This web application cross-check the contents of a file (File A), against another file (File B) to know if contents of file B is in file A 
## Instructions
1. Upload the file you want as the source of the cross-check in file A
2. Upload the file you want to be cross-checked in file B
3. Select the column header you want the cross check to be based on
4. Click on cross-check file
## Review
After the cross-check has been completed, you will see the result, stating the number of data that is in file A and the data in file A that is also in file B, and also, the data that is in file A that is not in file B with options to download both matched file and mising file.
